# MLP-DP 固定每节点资源结果

本表记录当前 DinD 方案的已验证基线。所有点均使用同一运行镜像、32,768 全局样本、3 次迭代、
每节点 1 CPU rank + 2 GPU worker、每节点 8 vCPU/16 GiB，以及跨节点单向 1 ms `netem`
延迟。所有 coordinator 均以 `exit=0` 自然结束。

| ---: | --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |

## 口径

- **总仿真时间**是 coordinator 的墙钟时间，包含 worker/coordinator 启动和结束回收，不包含
  外层 DinD Swarm 预配置。
- **稳态时间**是从 PipeComm 原始事件中提取的应用工作区间；单节点没有跨 rank 屏障，使用首个
  工作 header 到最后一个 payload 的等价边界。
- **同步时间**是跨节点 PipeComm 读阻塞时间的墙钟并集，不是所有 rank 的累计等待时间。

这是一轮单次测量，适合作为可复现实验基线，不应代替重复试验的均值、标准差或置信区间。2 节点
在本轮最短；4、8 节点的额外 rank group 增加了并行能力，但同步与运行时开销抵消了部分收益。
